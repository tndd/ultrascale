# UltraScale

3440 × 1440の外部モニタで、文字・UIの大きさを100〜200%の範囲で1%刻みに選ぶmacOSアプリです。縦横比を維持し、選んだ見かけの解像度の2倍で描画する仮想HiDPI画面を外部モニタへミラー表示します。整数ピクセルへの丸めにより各辺に最大0.5ピクセルの差があります。

`main`は通常利用向けの正式版です。倍率スライダー、適用後15秒以内の取り消し、メニューバー表示の切り替え、緑の標準アイコンを提供します。画面収録・アクセシビリティの許可は必要ありません。

フィルタ・シャープネス・画質調査・検証ツールは[画質調整の試験ブランチ](https://github.com/tndd/ultrascale/tree/codex/20261015_0645-pr-2-display-filters)に分離しています。試験ブランチの未検証機能を正式版には含めません。

## 使い方

1. 下記の手順でビルドし、`build/Applications.noindex/UltraScale.app` を開きます。必要ならFinderで「アプリケーション」へコピーできます。
2. 3440 × 1440の外部モニタを接続し、対象を選びます。
3. スライダーで倍率を選び、「HiDPIを適用」を押します。
4. 適用した設定はそのまま維持されます。15秒以内なら「変更前の表示に戻す」で取り消せます。直前にHiDPIを使っていた場合はその倍率へ、初めて適用した場合は通常表示へ戻ります。取り消しボタンは常に表示され、適用後15秒間だけ押せます。15秒経過すると無効になりますが、表示は変わりません。
5. 15秒経過後にHiDPI自体を解除するには、メニューバーの「元の表示に戻す」を使うか、アプリを終了します。

ウインドウを閉じてもHiDPI表示は継続します。メニューバーのディスプレイアイコンから再表示・解除・終了できます。画面下部の「メニューバーにアイコンを表示」でアイコンを非表示にでき、選択は次回起動時にも引き継ぎます。非表示のときもDockやLaunchpadから画面を再表示し、同じチェック項目でアイコンを戻せます。スリープ時は解除します。スリープ復帰後や再接続後は手動で適用してください。既存のミラーリングがある場合は先にシステム設定で解除してください。

未接続時にも倍率と見かけの解像度を確認できますが、適用は無効になります。内蔵画面へ適用する機能はありません。

## アイコン

標準は緑のスクリーン版（バーなし）です。予備として青いスクリーン＋角丸スライダーもアプリに収録しています。「UltraScale → Dockアイコン → 青／緑」から起動中のDockアイコンを切り替えられ、選択は次回起動時にも引き継ぎます。Finderに表示するアプリファイルのアイコンは緑です。

原画と透過素材は `Assets/Icons/` に保存しています。輪郭の切り抜きと各サイズへの変換はコードで再現できます。手順は [アイコン素材の説明](Assets/Icons/README.md) を参照してください。

| 倍率 | 見かけの解像度 | 内部の描画解像度 |
| --- | --- | --- |
| 100% | 3440 × 1440 | 6880 × 2880 |
| 125% | 2752 × 1152 | 5504 × 2304 |
| 150% | 2293 × 960 | 4586 × 1920 |
| 200% | 1720 × 720 | 3440 × 1440 |

## 対応範囲と制限

- 同梱バイナリはApple Silicon向けです。今回の動作検証環境はMacBook Air M4 / macOS 15.8.1です。
- 仮想画面は60 Hz・SDRです。HDR、可変リフレッシュレート、高リフレッシュレートは対象に含めません。
- 倍率の変更はモード切り替えです。ドラッグ中にデスクトップが連続アニメーションするものではなく、「適用」で切り替わります。画面の瞬断やウインドウの移動が起こる可能性があります。
- HiDPIは高解像度で描画してから縮小する方式です。モニタ自体の物理画素数は増えません。画質・負荷はモニタや接続構成によって異なります。
- 非公開の `CGVirtualDisplay` APIを使います。macOS更新後の互換性は保証されません。利用できない場合はエラーを表示します。
- 設定変更はアプリの動作中だけのCore Graphics設定です。システムファイル、ディスプレイのオーバーライド、SIP、ログイン項目は変更しません。画面録画は行いません。
- ローカルビルド用のアドホック署名です。Developer IDによる署名・公証は行っていません。

## 検証

検証内容と未検証事項は `VALIDATION.md` に記録しています。実際の3440 × 1440モニタで、追加確認なしで15秒を過ぎても125%を維持すること、適用直後の通常表示への取り消し、150%への変更を取り消して直前の125%へ戻ることを検証しました。画質の目視確認・抜き差し・スリープ復帰は未検証です。仮想画面での検証は実モニタでの検証を代替しません。

## ビルドとテスト

外部ライブラリやXcodeプロジェクトは不要です。AppleのCommand Line Toolsが必要です。

```bash
git clone https://github.com/tndd/ultrascale.git
cd ultrascale
./build.sh
open build/Applications.noindex/UltraScale.app
./test.sh
```

ビルド結果は標準で、リポジトリ内の `build/Applications.noindex/UltraScale.app` に出力されます。`./build.sh /任意の出力先/UltraScale.app` で変更できます。

実際のWindowServer APIで仮想画面・ミラー・復元を検証する場合は次を実行します。一時的な仮想画面を作成するため、テスト中はデスクトップ配置が変わる場合があります。

```bash
./test.sh --virtual
```

テスト用バイナリとUI画像はGit管理外の `build/` に出力します。UIテストはAppKitの実コントロールへアクションを送信し、ウインドウ内容を描画・検査します。ユーザーの実クリックや実モニタの目視検証とは区別しています。Web UIではないためPlaywright・組み込みブラウザは使用していません。

仮想画面のモード引数はこのMac上で実測しました。HiDPIモードには論理解像度を、ディスプレイの最大サイズにはその2倍のピクセル数を渡しています。

公開リポジトリ: [tndd/ultrascale](https://github.com/tndd/ultrascale)。アプリのビルド成果物とテスト画像はGit管理に含めません。

開発用アプリはSpotlightの検索対象にならない `Applications.noindex` 内へ出力します。通常利用するコピーは `/Applications/UltraScale.app` の1つに揃え、配布・退避にはZIPを使用してください。UIテストは終了時にテスト用アプリのLaunch Services登録を解除します。
